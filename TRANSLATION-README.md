# Translation and website changes

The original English and Spanish pages are retained. Every page has a language selector with more than 100 language options. English/Spanish load our locally hosted pages; other languages open Google Translate’s translated view of the corresponding live English page. This is **not** a collection of human-reviewed translations and is limited by Google Translate support, website accessibility and network availability. Visitors may encounter translation errors, especially in Scripture, names and testimony. Google processes translation requests under its own privacy terms. Translation cannot be previewed locally by opening HTML files directly: the website must be live.

Before publishing: review the website, back up the current hosted version, test English and Spanish navigation, mobile navigation, external translation from a published URL, and verify support/contact links. The existing live website is not modified by this ZIP.

## Important translation accuracy limits
- Only the English and Spanish source pages were edited. The machine-translated views for all other languages are created by Google at visit time; their final wording is **not included** in this ZIP and cannot be individually proofread or guaranteed to match the English.
- Bible quotations are not automatically translated from a certified Bible edition. If exact Bible wording and verse attribution matters, have a proficient reviewer check it against a clearly identified translation in that language.
- For best long-term fidelity, commission or verify translations of the core mission, donation and privacy statements, and testimony in the most visited languages. Maintain the English source as the reference, and revisit the translations whenever the source changes.
