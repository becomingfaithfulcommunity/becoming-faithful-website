Toma una foto

  1. Busca la aplicación Cámara y tócala una vez.
  2. Apunta al objeto que quieres fotografiar.
  3. Toca una vez el botón redondo grande.
  4. Toca la imagen pequeña para ver tu foto.

Envía un mensaje de texto

  1. Abre Mensajes.
  2. Toca el lápiz o Iniciar chat.
  3. Escribe un nombre y toca el contacto correcto.
  4. Toca el cuadro de texto y escribe tu mensaje.
  5. Revisa el nombre y toca la flecha para enviarlo.
